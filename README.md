# KenoxANON

Настольное приложение для Windows от **Kenox**: проверяет настоящий компьютер, объясняет найденное, помогает исправить и стирает цифровые следы — на диске, в файлах и в интернете. Всё на русском, всё работает на этом компьютере.

## Честно: сильные и слабые стороны

**Что получилось хорошо**

- **Всё локально.** Нет аккаунтов, серверов и телеметрии. В сеть уходит только то, что ты сам запустил (поиск, проверка ссылки, письмо), и об этом написано рядом с кнопкой.
- **Много автоматики:** «Проверить всё» одной кнопкой; Страж в фоне проверяет систему, стирает следы по расписанию и сам убирает место съёмки из новых фото; письма с требованием удалить номер в 7 определителей (GetContact, Truecaller и др.) одной кнопкой с твоей почты; трекер сроков ответа с напоминаниями и готовыми жалобами.
- **Редкие вещи:** поиск своего номера с проверкой каждой найденной страницы; метаданные HEIC, AVIF, WebP, MP3, M4A и FLAC с удалением по одному полю; «Двойник» — досье, которое можно собрать по твоим же файлам; «Рентген» сайтов во встроенном просмотре; зашифрованное хранилище данных.
- **Каждое изменение Windows показывается заранее** и откатывается одной кнопкой; необратимое (стирание) просит подтверждения.
- **Тесты:** форматы файлов, отправка писем (на поддельном сервере), защита сборки проверяются автотестами.

**Что слабо — и об этом лучше знать заранее**

- **Только Windows 10/11.** Нет версий для macOS, Linux и телефона.
- **Установщик не подписан** сертификатом разработчика: SmartScreen и часть антивирусов будут предупреждать. Весит ~116 МБ (это Electron).
- **Примерно половина утилит — полуавтомат.** Где действие делается внутри чужого аккаунта (Google, VK, Instagram…), приложение не входит туда за тебя: показывает шаги, открывает страницы по очереди и отмечает прогресс. Это сознательно — иначе пришлось бы хранить твои пароли и обходить капчи.
- **Поиск номера зависит от DuckDuckGo.** При частых запросах он временно просит капчу; Яндекс и Google автоматически не опрашиваются (только готовые ссылки).
- **Базы «пробива» не проверяются и не будут** — это украденные данные.
- **Проект делает один человек**, независимого аудита безопасности не было. Юридические тексты (152-ФЗ, GDPR) — шаблоны, а не юридическая консультация.
- **Поддержка форматов файлов проверена на синтетических файлах**; на редких вариантах записи что-то может не распознаться (тогда приложение честно пишет, что не смогло, и не трогает файл).

## Защита самой программы

- Окно интерфейса изолировано (sandbox, contextIsolation, без Node), строгая CSP, только свои скрипты.
- Команды главного процесса принимаются только от собственной страницы приложения; встроенный просмотр сайтов работает в отдельной сессии без доступа к ним.
- Запрещены вложенные webview, новые окна, разрешения (камера, микрофон, геопозиция) для окна приложения; в установленной версии не открываются инструменты разработчика.
- Предохранители Electron: нельзя запустить программу как Node, подсунуть код через `NODE_OPTIONS` или `--inspect`; программа загружается только из `app.asar`, а его целостность проверяется — изменённая копия не запустится.
- Хранилище данных шифруется AES-256-GCM, ключ — из пароля через scrypt. Пароли приложений почты и ключи сервисов не сохраняются.

Нашёл уязвимость — напиши в Issues с пометкой `security` (без подробностей эксплуатации в открытом виде).

## Установка

Скачай `KenoxANON-Setup-<версия>.exe` из раздела Releases. Установщик спросит папку, создаст ярлыки; удаляется приложение как обычная программа через «Параметры → Приложения».

Так как установщик не подписан, при первом запуске Windows SmartScreen может показать «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

## Запуск из исходников

Нужен [Node.js](https://nodejs.org) 20 или новее:

```bash
git clone https://github.com/Kenox/KenoxANON.git
cd KenoxANON
npm install
npm start
```

Собрать установщик заново:

```bash
npm run dist
```

Готовый файл появится в `release/`. Иконка рисуется скриптом `scripts/icon.js` (тот же пиксельный знак 3×3, что в шапке сайта).

## Что внутри

**Обзор.** Индекс невидимости (0–100 %) по реальным настройкам системы, список «Сначала это», плитки слоёв, стирания и инструментов. «Исправить безопасное» применяет все правки без прав администратора, предварительно показав их списком. `F5` — проверить заново.

**Девять слоёв.** Живые проверки: что сейчас стоит в системе, почему это важно, кнопки «Исправить» и «Вернуть как было». В первом слое выбирается противник, и приоритеты перестраиваются под него.

### Утилиты

Отдельный раздел с небольшими помощниками для конкретных дел — всего их будет 70, они появляются по пять за раз (готовые помечены «готово», остальные — «скоро»). Сверху поиск: можно искать по словам («телефон», «Google», «флешка») или по номеру; рядом фильтры по шести группам и «только готовые». Нажми на утилиту — откроется окно: сначала справка (что делает, как пользоваться и **что произойдёт** — что изменится, что уйдёт в сеть, что нельзя вернуть), потом кнопки. У каждой утилиты подписано, что она делает с компьютером: только справка, только проверка, обращение к сайту, изменение настроек с откатом или стирание без возврата.

### Двойник

Досье на тебя по твоим же данным: что может узнать тот, кому попали твои файлы или фото. Выбираешь папки (по умолчанию «Изображения», «Рабочий стол», «Загрузки», «Документы», «Видео») и нажимаешь «Собрать досье». Двойник читает только метаданные и показывает выводы с уровнем уверенности:

- **где ты живёшь и работаешь** — по координатам снимков: где чаще снимаешь вечером и в выходные, где днём по будням; точки рисуются на пиксельной схеме без загрузки карт из сети;
- **чем снимаешь** — модели камер и серийные номера;
- **как тебя зовут** — авторы документов, организация, имя пользователя Windows и имя компьютера;
- **распорядок дня** — когда ты активен и когда спишь;
- **где бываешь** — сохранённые сети Wi‑Fi; **чем пользуешься** — мессенджеры, игры, VPN, криптокошельки; **с кем общаешься** — по переписке в хранилище; **кому виден компьютер** — текущие соединения.

Рядом с выводами — кнопки: стереть место съёмки из всех найденных снимков, стереть серийные номера камер, стереть авторов из документов, забыть сети, удалить забытые аккаунты. Досье считается на этом компьютере и нигде не сохраняется.

### Анонимный поиск

Поиск через DuckDuckGo с выдачей в стиле приложения. Запросы идут из отдельной сессии, которая живёт только в памяти: без cookies, кэша и истории, с обычным браузерным User-Agent. После каждого запроса сессия очищается, а текст запросов нигде не записывается — ни в журнал, ни в настройки. Соединение: напрямую, через SOCKS5 или HTTP-прокси, есть кнопки для Tor Browser (127.0.0.1:9150) и службы Tor (127.0.0.1:9050). «Проверить соединение» показывает, какой IP видят сайты и идёт ли трафик через Tor. Можно выбрать регион, период и безопасный поиск. Прокси с логином и паролем пока не поддерживаются.

Найденное открывается прямо в приложении — через то же соединение и тоже без истории:

- **«Читалка»** — текст страницы в оформлении KenoxANON: без скриптов, картинок, рекламы, трекеров и всплывающих окон. Ссылки в статье открываются тут же, метки слежки (`utm_*`, `fbclid`, `yclid` и другие) из них убираются. Наверху видно, сколько читать и сколько скриптов и картинок не загрузилось.
- **«Оригинал»** — сам сайт во встроенном окне, отделённом от приложения: трекеры (Google Analytics, Яндекс Метрика, пиксели соцсетей и другие) блокируются, сайтам не сообщается, откуда ты пришёл, WebGL выключен, WebRTC не выдаёт настоящий IP мимо прокси, всплывающие окна, загрузки и доступ к камере, микрофону и геопозиции запрещены. JavaScript выключается одной кнопкой.

**«Рентген сайта»** — панель справа от «Оригинала»: какие трекеры сайт пытался загрузить (и кто за ними стоит: Яндекс Метрика и Вебвизор, Google, Top@Mail.ru, пиксели соцсетей, системы записи действий, рекламные биржи) — все они остановлены; на какие чужие серверы он ходил; какие cookies ставил, чьи они и на сколько; о чём просил (уведомления, камера, геопозиция — всё отклонено). Отчёт собирается из сетевых запросов, сам сайт его не видит; на новой странице он начинается заново. В «Читалке» вместо этого видно, какие трекеры прописаны в коде страницы (там они не запускаются).

**Тихие закладки** — кнопка «★ Сохранить в хранилище» в «Читалке» кладёт текст страницы с метками в «Хранилище данных» → «Закладки». Потом его можно читать без сети в том же оформлении; браузер и его история об этом не знают.

Есть «назад/вперёд» (и Alt+←/→) и адресная строка — в неё можно вписать адрес или новый запрос; Esc возвращает к результатам, выбранный режим запоминается. Закрыл просмотр или ушёл в другой раздел — всё, что сайты успели сохранить (cookies, хранилища, кэш), стёрто. Кнопка «в своём браузере ↗» откроет ссылку в обычном браузере — он ходит в сеть своим путём, мимо прокси.

### Страж

Фоновый режим: значок у часов, приложение работает и после закрытия окна (крестик прячет окно, «Выйти» — в меню значка). Что делает:

- **проверка по расписанию** — каждый день или неделю и уведомление, только если защита стала хуже (например, обновление Windows выключило брандмауэр);
- **автоочистка** — сама стирает выбранные следы при запуске компьютера и/или каждые 1, 6 или 24 часа; по умолчанию выключена, пока ты её не включишь;
- **камера и микрофон** — уведомление сразу, как только программа их включила;
- **сводка за неделю**, **тревога** из меню значка и **запуск вместе с Windows** (незаметно, значком у часов).

### Хранилище данных

Все твои данные из разных сервисов — в одной базе SQLite на этом компьютере (`%APPDATA%\KenoxANON\vault.db`). Работает в три шага:

1. **Загрузить.** Перетащи официальную выгрузку сервиса — ZIP-архив, JSON, HTML, CSV, VCF, TXT или распакованную папку — или добавь папку с фото и файлами. Понимаются: Telegram (экспорт в JSON), Discord (пакет данных), Google Takeout (история Chrome, закладки, «Мои действия» и YouTube в JSON, контакты), Instagram и Facebook (JSON), WhatsApp (экспорт чата в .txt), закладки любого браузера (HTML), контакты телефона (.vcf) и таблицы CSV. Распознавание идёт по содержимому файлов, поэтому подходят и выгрузки с русскими названиями папок. Повторная загрузка не создаёт дублей. Внутри приложения есть короткие инструкции, где взять каждую выгрузку.
2. **Найти.** Разделы «История», «Закладки», «Контакты», «Сообщения», «Медиа», «Файлы», «Активность», полнотекстовый поиск с подсветкой (в том числе по-русски), метки, график активности по месяцам и самые частые собеседники.
3. **Удалить.** Отдельную запись, всё найденное, целый источник или всё хранилище (файл базы перезаписывается случайными байтами и удаляется).

**Пароль на хранилище.** По желанию база целиком шифруется: AES-256-GCM, ключ данных случайный и сам зашифрован ключом из твоего пароля (scrypt). На диске остаётся только зашифрованный файл `vault.kxv`, а открытый `vault.db` перезаписывается случайными байтами и удаляется. Пока хранилище открыто, расшифрованная копия живёт только в памяти. Оно запирается само: через выбранное время без действий (5 минут — 4 часа или никогда), когда блокируешь Windows или компьютер засыпает, по желанию — когда окно уходит в трей, а также при тревоге и выходе из приложения. Пароль можно сменить или снять. Пароль нигде не сохраняется: забыл его — данные не вернуть, можно только стереть хранилище и начать заново.

Сюда попадает только то, что ты сам загрузил, указал или сохранил из «Читалки». Пароли и данные платёжных карт не импортируются, из профиля Discord берутся только друзья (без почты, телефона и IP). Из папок с фото и файлами записываются только имена, размеры и даты — содержимое не читается. Удаление в хранилище стирает только копию в KenoxANON: сами сервисы и файлы не меняются. Ничего не отправляется в сеть.

### Стирание

- **Следы в Windows.** Сканирует и стирает одной кнопкой: недавние файлы и списки переходов, историю «Выполнить» и адресной строки, историю поиска в проводнике, буфер обмена и журнал Win+V, временные файлы старше суток, кэш эскизов (миниатюры удалённых фото), отчёты об ошибках, кэш DNS, корзину, кэш Telegram Desktop и Discord, Prefetch (через UAC). Рядом — ссылки на скрытые кнопки очистки самой Windows: журнал действий, диагностические данные, журнал поиска, журнал местоположений.
- **Шредер файлов.** Файлы и папки перезаписываются случайными байтами, получают случайное имя и удаляются. Системные папки, целые папки профиля и сам KenoxANON защищены; подтверждение требует отдельной галочки. Там же — затирание свободного места встроенной командой `cipher /w` с подсказкой, нужно ли это твоему диску (для SSD обычно нет).
- **След в интернете.** Страницы удаления аккаунтов 24 сервисов с отметками «удалил», поиск забытых регистраций, удаление себя из Google, Яндекса и Bing, история в сервисах Google, Microsoft, Apple и Яндекса и генератор требований об удалении данных: по 152-ФЗ, по GDPR и заявление поисковику по «праву на забвение» (ст. 10.3 149-ФЗ). Текст собирается на компьютере и копируется в буфер — никуда не отправляется.
- **Метаданные.** Фото (JPEG, PNG), видео с телефона (MP4, MOV), PDF и документы Office: место съёмки, камера и её серийный номер, миниатюра до обрезки, XMP, автор, редакторы и комментаторы документа с их почтой, организация, даты. У каждого поля — кнопка «удалить», у файла — «Удалить метаданные» целиком, «Чистая копия» рядом и «Стереть файл» шредером. Перезапись идёт через временный файл с проверкой, дата файла и поворот фото сохраняются.
- **Браузеры.** Кэш, cookies вместе с данными сайтов и метками HSTS (там прячутся суперкуки), история с вкладками и значками сайтов, автозаполнение — для Chrome, Edge, Яндекс Браузера, Brave и Firefox. Закладки, пароли и расширения не трогаются.
- **Тревожная кнопка** по желанию сразу после блокировки экрана стирает журнал Win+V, недавние файлы и историю «Выполнить» и поиска.

### Инструменты

Радар соединений, «Кто подглядывал» (камера, микрофон, геопозиция, уведомление в фоне), утечки паролей с проверкой без отправки пароля и мастером смены паролей почт, эфир Wi‑Fi, тревожная кнопка с горячей клавишей `Ctrl+Alt+Shift+K`.

**Атлас слежки** — 32 термина с сайта. Карточка каждого термина говорит, можно ли его стереть: 8 стираются прямо из атласа (кнопка «Стереть»: кэш DNS, хранилища браузеров, история, метки HSTS и значков, EXIF, сохранённые сети), 6 — частично (логи — через требование к сервису, даты в файлах, кэш с метками пикселей, ID отпечатка в хранилищах сайтов, словарь набора Windows), а 18 стереть нельзя — они вычисляются заново при каждом визите или хранятся у провайдера; для них в карточке объяснено почему. Вторая кнопка ведёт на нужную страницу программы: она открывается с плашкой «Из атласа», нужное уже отмечено. Зелёный квадрат у термина — стирается, жёлтый — частично. **Журнал** — каждое исправление, откат, очистка и стирание записываются с хэшем SHA-256, в который вшит предыдущий.

## Безопасность

- Перед любым изменением показывается, что именно поменяется или будет стёрто. Необратимые действия (шредер, стирание файла) требуют отдельной галочки «понимаю».
- Настройки учётной записи (`HKCU`) меняются без прав администратора; системные (брандмауэр, DNS, удалённый доступ, телеметрия, Prefetch) — только через окно UAC, которое подтверждаешь ты.
- Для настроек сохраняются прежние значения, «Вернуть как было» восстанавливает их. Стёртые файлы и следы вернуть нельзя — так и задумано.
- Откаты, журнал и настройки лежат в `%APPDATA%\KenoxANON`. Запуск с ключом `--kx-data=<папка>` использует отдельный профиль.
- Пароли нигде не сохраняются, в том числе пароль хранилища: от него хранится только зашифрованный ключ, по которому пароль не восстановить. Сгенерированный пароль стирается из буфера обмена через 30 секунд.
- Наружу уходит только: первые 5 символов SHA-1 проверяемого пароля (api.pwnedpasswords.com), адрес почты — если ты сам запустил проверку с ключом HIBP, обратные DNS-запросы, когда просишь радар назвать сервер, поисковые запросы в DuckDuckGo и страницы, которые ты сам открыл из выдачи (через выбранный прокси), и проверка соединения (check.torproject.org). Ссылки на сервисы открываются в твоём браузере.
- Интерфейс работает в песочнице Electron (`contextIsolation`, `sandbox`, строгая CSP) и общается с системой только через перечисленные команды.
